# 钢四参谋 · HOI4 Advisor

给 [N.E.K.O](https://github.com/Project-N-E-K-O/N.E.K.O) 用的《钢铁雄心4》参谋插件。

你说话，她替你动手：报战况、调兵、划线、看编制。**决策权在她（模型）手上，代码只负责观察、执行、如实汇报。**

```
你说「报一下前线」   → 她读出实时交火、控制方、兵力比，讲给你听
你说「把第4集团军铺在波兰正面」 → 她点名省，代码按引擎规则把兵摆过去
你说「这几个师去克拉科夫」   → 代码用引擎自己的下单函数把行军路线写进部队
```

---

## 它是什么

两个部分，一起发布：

| 部分 | 语言 | 干什么 |
|---|---|---|
| **插件本体** | Python | 读存档、认地名、算路径、调工具、跟宿主 N.E.K.O 通信、面板 UI |
| **进程内代理** | C（`dll/`） | 注入 `hoi4.exe`，通过 TCP 7801 提供读内存 / 调用引擎函数的能力 |

代理是**外挂性质**的：它 `ReadProcessMemory` 读游戏、`WriteProcessMemory` 改游戏里的结构，并调用引擎自己的函数（下单、选国策）。

## 安装

1. 从 [Releases](../../releases) 下最新的 `hoi4_advisor.neko-plugin`
2. N.E.K.O → 插件页 → 安装该文件
3. **完全退出** N.E.K.O（不是最小化）再打开
4. 打开插件面板「世界资料库」，按四步引导走一遍（找游戏 → 选世界 → 读取 → 完成）
5. 进游戏，进到地图界面

代理**不需要手动注入**：第一次真正用到内存时（体检、报前线、调兵），插件会自动把 `neko_hoi4_agent.dll` 注入进去。注入失败会告诉你卡在哪一步，不会只说"出错了"。

## 世界资料库（换 mod 不用改代码）

以前地图知识写死在一个按**原版** `provinces.bmp` 生成的索引里。换个大 mod（The Fire Rises 把整张地图、州划分、省份编号全换了）就整体错位：你说"去华沙"，她落在毫不相干的地块上。

现在「一个世界 = 游戏版本 + 一组启用的 mod」，各自生成一份数据：

```
<插件数据目录>/atlas/<world_id>/
  meta.json        版本 / mod 名 / 各项计数 / 指纹 / 数据来源
  provinces.json   省 id → {x, y, area}
  states.json      州 id → {name, provs}
  countries.json   TAG → 本地化国名
  cities.json      胜利点数 → 城市名
  adjacency.json   省 → 相邻省
```

换 mod 只是多一份数据。实测规模：

| 世界 | 省 | 州 | 国名 | 邻接 |
|---|---|---|---|---|
| 原版 1.16.9 | 13,375 | 1,016 | 301 | 9,924 |
| The Fire Rises 1.0.6a | 14,973 | 1,444 | 562 | 11,500 |

生成耗时 8~15 秒。原版那份与随包快照**逐省零差异**。

## 她会做什么 / 不会做什么

**做**（都只读或只动玩家自己的师）：

- 读实时交火、交战线、控制权、兵力分布
- **一键铺前线**：说「把前线铺上」，她机械地算出所有挨着交战国的自家省（实测 28 个），
  按引擎自己的摆兵规则铺上去——不用你先报省号
- **推一格**：点一个紧挨着的敌省，只让挨着那一格的部队打过去；别处的守线部队一个都不动，
  出发省至少留一个师守家。**守线的师照样能进攻，不用先撤下来，线也不会空**
- **点谁守哪里**：units=第3山地师 只动你点名的师，别处一个不碰
- **画进攻线**：给一个目标 + 派哪几个师，这几个师就一格一格推过去，
  每格都留人填线；上一格没打下来不重复下令，哨兵每轮自动往下走一格
- **微操**：units= 点名可以让**某一个师**去打某一点，或者只把它绕到某个省
- 把预备队调去某个我方省、回防、换防（跨省太远时会提醒「中途没有接应」）
- 读编制、师番号、将领、国策进度

**不做**（写死在代码里，不是靠提示词约束）：

- **不宣战、不吞并、不切国家、不读档存档、不写存档**
- **不动别的国家的部队**
- **不做战术决策**：守哪些省、往哪推，由模型或你定；代码只执行
- **不判断打不打得下来**：那是战场结果

标定偏移是从 **1.16.9** 逆出来的，记录在 ssets/live_symbols.json：
版本判定靠 **exe 大小 + 版本串**（uild.exe_size / uild.hofix），不靠路径——
所以那个文件里的 exe 只留文件名，标定时的本机绝对路径不入库。
exe 大小对不上就只让看不让动。

## ⚠ 风险声明（请读完再装）

1. **这是注入型工具**，会读写 `hoi4.exe` 的进程内存。杀毒软件可能报毒或拦截，这是注入行为的正常反应，不是误报。
2. **只用于单机存档**。多人游戏使用内存注入工具可能违反 Paradox 的用户协议，也可能被判定作弊。**不要在联机局里用。**
3. 写内存的前提是偏移与 exe 版本严格匹配。版本变了插件会拒绝写入，但**任何内存工具都不保证绝对安全**——请先备份存档。
4. 本项目与 Paradox Interactive 无关，不含任何游戏本体文件。

## 目录结构

```
plugin.toml            插件清单（入口、面板、权限）
__init__.py            插件主体：工具/入口注册 + 业务编排
livegame.py            实时内存：连代理、读国家/省/师/交火、下单、路径
command.py             接管部队：守线摆兵、配额、冲突检测
battleplan.py          战区前线对象读写（引擎函数）
nekoagent.py           代理客户端（TCP 协议 + 注入）
bridge_launcher.py     DLL 注入
atlas.py               世界资料库解析器（合并 mod / 扫图 / 州 / 国名 / 指纹）
panel.py               面板后端
static/                面板前端（四步引导 + 管理页，内联 SVG）
dll/
  neko_hoi4_agent.c    代理源码（内存读写 + 引擎函数调用）
  neko_hoi4_agent.dll  预编译产物
  neko_hoi4_bridge.c   桥接源码
  BUILD.md             怎么重新编译
mod/yui_command/       游戏内决策 mod（语音指令走这里）
prov_px.json           旧版坐标索引（资料库缺失时的兜底）
assets/                偏移符号表等运行数据
tools/                 打包 / 发布脚本
```

## 从源码构建

**代理 DLL**（需要 [zig](https://ziglang.org/)，不用装 MSVC）：

```bash
zig cc -target x86_64-windows-gnu -shared -O2 \
    -o neko_hoi4_agent.dll neko_hoi4_agent.c -lws2_32 -luser32
```

细节见 `dll/BUILD.md`。

**插件包**：

```bash
python tools/build_plugin.py --out dist/hoi4_advisor.neko-plugin
```
